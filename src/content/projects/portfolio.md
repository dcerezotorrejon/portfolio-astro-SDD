Es el sitio que estás viendo. Se genera de forma estática con Astro y usa React únicamente en las islas interactivas, como el navegador flotante y el carrusel de proyectos.

El perfil, la trayectoria profesional y los proyectos viven en colecciones de Markdown validadas con esquemas, de modo que un contenido inválido hace fallar la compilación en lugar de llegar publicado.

Los estilos usan Tailwind CSS v4 y las pruebas combinan Vitest, la API de contenedores de Astro y axe-core, además de Playwright para la integración en el navegador.
